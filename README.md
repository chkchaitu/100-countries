# 100 Countries

A static, interactive atlas for Indian passport holders: low-budget multi-country trips, visa rules, best months, day-by-day plans and unusual experiences.

**Status:** early version. The atlas covers 143 countries: the 101 that the 18 trips add, plus 14 popular hub countries and 28 added on request. Each has a visa rule for an Indian passport with sources and a check date, and a profile with places, best months, budget, transport and cautions. Experiences and records lists are still partial. Prices, visa rules and opening hours are estimates from research on 16 October 2026 and must be confirmed with official sources before booking. This is not legal, visa or travel advice.

## Run it

Open `index.html` in a browser. There is no build step and no server.

## Privacy

Nothing a visitor ticks (visited countries, plan, visas) leaves their browser. It is stored in `localStorage` only.

## Data and sources

Map shapes come from Natural Earth via the `world-atlas` package (public domain). Content is rewritten from research with sources recorded per item; add a source link and a "last checked" date to every record before publishing it.

## Contributing

Issues and pull requests that correct a fact should include an official source link.

## Vision

The goal today is to help people who dream of visiting 100 countries. The aim is a one-stop planner for anyone travelling from India to any country in the world: visa requirements, places to visit, itineraries, best months, budgets and practical tips, all with sources and a last-checked date. Countries are added a few at a time.
